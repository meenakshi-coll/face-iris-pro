# Face and Iris Multimodal Biometric Authentication System

## Project Overview
This project implements a **Face and Iris Multimodal Biometric Authentication System** using Machine Learning and Computer Vision techniques. The system improves authentication accuracy by combining **face recognition** and **iris recognition** for secure user identification.

## Objectives
- To develop a secure biometric authentication system
- To combine face and iris recognition techniques
- To improve accuracy and security compared to single biometric systems
- To perform biometric identification using machine learning models

## Technologies Used
- Python
- OpenCV
- NumPy
- Matplotlib
- Scikit-learn
- Google Colab / Jupyter Notebook

## Dataset
The project uses **Face and Iris image datasets** for biometric authentication and recognition.

## Features
- Face image processing
- Iris image processing
- Feature extraction
- Classification and recognition
- Accuracy evaluation

## Project Workflow
1. Data Collection  
2. Image Preprocessing  
3. Feature Extraction  
4. Model Training  
5. Face and Iris Recognition  
6. Authentication Result

## How to Run the Project
1. Clone the repository:
```bash
git clone https://github.com/meenakshi-coll/face-iris-project.git
```

2. Open the notebook file in Google Colab or Jupyter Notebook.

3. Install required libraries:
```bash
pip install opencv-python numpy matplotlib scikit-learn
```

4. Run all notebook cells.

## Results
The system recognizes face and iris patterns and provides authentication with improved accuracy.
